# Changelog

## 1.0

Preserves the hardware-confirmed Test 5 binary and source implementation.

- Working career/time-trial gameplay, graphics, effects, saves and New 3DS controls.
- Console control labels and Select camera input.
- Bottom-screen splash, contextual prompts, loading indicator and supplied icon.
- Normalized soundtrack, city selection, splash timing, fades and one-shot results music.
- Independent music playback through loading screens, with volume/mute support.
- Buffered crash diagnostics retained.
- Standalone Python game-data extractor and three release packaging options.
